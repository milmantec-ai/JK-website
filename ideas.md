# Design Brainstorm: JK Bhairava Painting Service Website

Since this is a **replication** of an existing WordPress website with only two targeted modifications (hero slider and footer simplification), the design approach must faithfully match the existing site's aesthetic rather than introduce a new design system.

## Existing Site Design Analysis

The current website uses the **Autixir** WordPress theme with the following established design language:

- **Fonts**: Open Sans (body) + Rajdhani (headings) — both Google Fonts
- **Colors**: Dark navy/charcoal backgrounds (#0d1b2a), lime green accents (#00ff00), red CTAs (#e74c3c), white text on dark, dark text on light sections
- **Layout**: Full-width sections, centered content, card-based service display
- **Style**: Professional trades/services aesthetic with bold headings and clean spacing

## Selected Approach: Approach 1 — Faithful Replica with Subtle Polish

This is the correct choice because the user explicitly requested to **keep the current design** and only modify the hero and footer. The design must match the existing site as closely as possible.

### Design Specifications
- **Fonts**: Open Sans (300-800) for body, Rajdhani (300-700) for headings
- **Primary Dark**: #0d1b2a (dark navy background)
- **Accent Green**: #00ff00 (lime green subtitles/accents)
- **CTA Red**: #e74c3c (red buttons)
- **White**: #ffffff (text on dark, backgrounds)
- **Light Gray**: #f5f5f5 (light section backgrounds)
- **Hero Slider**: Smooth crossfade, 5-second auto-advance, dot navigation, same overlay style
- **Footer**: 2 clean columns — business info + navigation, same dark background
